# Cube.AI public experiences

- [Try the prototype](https://www.blairsu.design/cube/prototype/): start a blank board.
- [See the demo](https://www.blairsu.design/cube/demo/): explore the seeded onboarding example.

These are static browser applications served by GitHub Pages from the main branch of Blair-Su/design. They do not require an account or an application server. The public build also includes this directory.

Boards are saved in each visitor's browser. Prototype and demo use separate storage namespaces. Sharing the application URL opens the application, not the sender's board; board files can be exported and imported separately.

Keep asset references and cross-links relative so both applications work within their own subdirectories.
