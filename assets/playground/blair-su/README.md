# Blair Su — original portfolio hero

Source: Blair-Su/Blair-Portfolio, commit 9eae283f485c3c360546a854e70e89d0d7c11786.
The original Unicorn Studio 1.4.25 renderer, compiled scene definition, environment image and Blair Su SDF texture are retained together. Shader parameters are unchanged.

The Playground frame supplies a 4:3 thumbnail viewport, the existing sky background, lazy initialization, hidden-card pausing and reduced-motion handling. The plain lettering shown while loading or without WebGL is a fallback, not the original shader output.

Browser/GPU comparison remains unverified: the computer-use browser could not verify its administrative access policy. No alternate browser or headless renderer was used to bypass that restriction. Navigation, asset references and lifecycle behavior were checked locally.
